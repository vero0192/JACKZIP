# Motion system

Idle is quiet. JAX's body does not continuously bob or bounce. Scan rings activate only in the extracting, matching, or analysis stages.

Processing stages are driven by actual workflow state: reading, postal lookup, ACS, ranking, completion, error, or cancellation. No fabricated percentages are used.

Short effects use transforms/opacity. Particle elements clean up after animation end, cancellation, or a bounded fallback. FX off clears particles and cancels active Web Animations. Result values are shown directly, without counting through invented monetary values.

The operating-system reduced-motion preference disables nonessential CSS motion, including pseudo-elements. Script-driven scrolling respects that preference and the in-app FX toggle. State text and hierarchy remain available.

Chart bars settle before comparison checks. Completion removes active scan styling. Stale or cancelled network callbacks cannot restart the pipeline indicator.
