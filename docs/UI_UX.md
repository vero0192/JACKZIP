# JACKZIP interface

The command center uses graphite surfaces, bone text, acid highlights, restrained cyan geographic structure, and the current hooded JAX artwork. JAX supports the task; results remain dominant.

The desktop workspace navigation exposes Home, Paste, Analyze, STACK, Table, Chart, Map, Export, and Settings. On mobile it becomes a horizontally scrollable navigation strip. All controls perform real actions.

Space Grotesk and IBM Plex Mono are served locally with fallback fonts and included licenses. The current JZ STAR is an angular asymmetric signal mark; raster app icons are rendered from the same vector.

STACK prioritizes ZIP, area-level income, place/state, occurrence count, ZCTA, and MOE. JAX is restrained in the shell and result hero. Immersive STACK uses focus containment and restores focus on close.

Table, Chart, and Map show the same page of command-selected results. Dossier exposes methodology, lookup/context statuses, occurrence IDs and source-line numbers. Unavailable records remain in Review. Exports include the full command selection plus canonical unresolved records.

Pages contain 50 ranked results to bound rendering cost. This is not a limit on extraction, ranking, or exports.

Motion reflects processing state. Completed states stop scanning. Reduced motion and the FX toggle remove nonessential animation while keeping state feedback.
